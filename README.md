# ChoiceModelOptimizer

Массовое облегчение пака моделей для Warcraft III 1.26. Программа уменьшает и пережимает текстуры `.blp` и снижает число частиц в моделях `.mdx`, чтобы карта меньше весила и меньше нагружала игру.

Обрабатывается целая папка вместе со всеми подпапками. Модели внутри `.w3x` и `.mpq` программа не видит: их сначала нужно извлечь в папку (например, через MPQ Editor), обработать и положить обратно.

## Состав

| Файл | Что это |
|---|---|
| `ChoiceOptimizerGui.exe` | Программа с окном: все настройки в одном месте |
| `ChoiceOptimizer.exe` | Консольная версия, её запускают `.bat`-файлы |
| `Урезать.bat` | Пробный прогон папки, затем запись после подтверждения (`y`) |
| `Отчёт.bat` | Отчёт по папке, ничего не меняет |
| `src\` | Исходники и `build.bat` для сборки |

## Быстрый старт

1. Откройте `ChoiceOptimizerGui.exe` и укажите папку с моделями: через «Обзор…» или перетащив её в окно.
2. Нажмите «Пробный прогон». Файлы не меняются: в журнале будет видно, что программа собирается сделать, и сколько будет весить папка после записи.
3. Если всё устраивает, нажмите «Урезать».

Без окна: перетащите папку на `Урезать.bat`.

## Что делает программа

### Размер текстур

| Режим | Что происходит |
|---|---|
| По правилу (по умолчанию) | Больше 512×512 — в 4 раза по стороне (1024×1024 → 256×256). Ровно 512×512 — в 2 раза. Меньше — не трогаются |
| Не менять размер | Размер остаётся прежним, текстура только пережимается |
| Все до 512 / 256 / 128 | Каждая текстура, у которой большая сторона больше N, уменьшается до N |

Без пережатия текстура уменьшается без потерь: основной картинкой становится уменьшенная копия (мип-уровень), которая уже лежит внутри BLP, и качество не меняется.

### Сжатие JPEG

Ползунок и поле «Сжатие JPEG» задают качество от 0 до 100, по умолчанию 65. Алгоритм тот же, что у генератора иконок `tools/icons/blp1.py`.

- Пересохраняются только JPEG-текстуры, у которых качество выше заданного больше чем на 2. При 65 текстуры с качеством до 67 включительно не трогаются: повторное сжатие почти ничего бы не дало, а картинку испортило бы.
- Пиксели и прозрачность остаются как есть. Прозрачный контур в 1 пиксель, как у иконок, не добавляется.
- Мип-уровни строятся заново, всегда полной цепочкой до 1×1: у 512×512 это 10 уровней, у 1024×1024 — 11, у 256×256 — 9. После записи программа проверяет каждый уровень.
- Пережатие никогда не добавляет вес. Если пережатый файл получился не меньше, чем без пережатия, текстура остаётся в исходном качестве: либо как была, либо, если её нужно уменьшить, уменьшается готовыми мип-уровнями. В журнале такие текстуры помечены «без пережатия — качество исходное (qNN)».
- Палитровые BLP не пережимаются.
- 0 — не пережимать.

### Частицы

Затрагиваются только эмиттеры частиц (Particle Emitter 2) в `.mdx`. Частота появления частиц снижается, а сами частицы становятся крупнее (размер растёт на корень из коэффициента урезания), так что эффект закрывает примерно ту же площадь.

| Когда | Что |
|---|---|
| Эмиттер держит больше 1000 частиц одновременно | Частота до ~600, не больше чем в 4 раза |
| Выброс больше 200 частиц за раз | До ~150, не больше чем в 4 раза |
| Модель держит больше 1000 частиц в сумме | Частота всех эмиттеров до 2 раз меньше |

Время жизни, цвет, скорость и текстура частиц не меняются.

**Может ли урезание частиц вызвать краш?** Практически нет. Программа ничего не удаляет из модели, а только меняет числа в уже существующих полях. Размер и структура файла остаются прежними. На синхронизацию это тоже не влияет: частицы рисует каждый компьютер сам, в игровую логику они не входят.

### Только эти текстуры

Если вписать имена `.blp` через запятую (или нажать «Выбрать…»), урезаются только они: ещё в 2 или в 4 раза по стороне от текущего размера. Всё остальное не трогается. Удобно, чтобы дополнительно облегчить, например, одного тяжёлого героя.

## Безопасность и повторные запуски

- **Резервные копии.** Перед первым изменением оригинал копируется в `<папка>_backup` (путь можно поменять). Уже лежащая там копия не перезаписывается, поэтому всегда хранится самый первый оригинал.
- **Повторный запуск.** Обработанные файлы записываются в `_packfix_done.txt` и при следующем урезании пропускаются. Галочка «Заново и уже обработанные» (`--force`) урезает их ещё раз.
- **Уже урезанная вручную папка.** Кнопка «Отметить всё как обработанное» (`--mark-done`) записывает все текущие файлы в `_packfix_done.txt`, ничего не меняя.
- **Проверка результата.** Если текстура после обработки не прошла проверку, она остаётся как была, а в журнал пишется `BAD`.

## Журнал и отчёт

- **Журнал** `_packfix_log.txt` пишется в обрабатываемую папку при каждом прогоне: что и как изменено, ошибки, а в конце строка с общим весом папки:
  ```
  Общий вес папки: 8.0 -> 1.7 МБ (после записи), меньше на 6.3 МБ (79%)
  ```
  В пробном прогоне вес «после» рассчитан заранее. Служебные файлы `_packfix_*.txt` в вес не входят.
- **Отчёт** (кнопка «Отчёт» или `Отчёт.bat`) ничего не меняет. Он показывает распределение текстур по качеству JPEG, текстуры с неполной цепочкой мип-уровней, самые тяжёлые модели по частицам и самые крупные текстуры.

## Консольная версия

```
ChoiceOptimizer <папка> [параметры]
```

| Параметр | Что делает |
|---|---|
| без `--write` | Только пробный прогон и журнал |
| `--write` | Изменить файлы |
| `--backup <папка>` | Куда копировать оригиналы (по умолчанию `<папка>_backup`) |
| `--textures-only` / `--particles-only` | Только текстуры / только частицы |
| `--max N` | Все текстуры больше N по большей стороне уменьшить до N |
| `--keep-size` | Размер текстур не менять, только пережатие |
| `--quality Q` | Качество JPEG при пережатии, по умолчанию 65; `0` — не пережимать |
| `--half a.blp,b.blp` | Только эти текстуры ещё в 2 раза; с `--half4` — в 4 раза |
| `--force` | Обработать и файлы из `_packfix_done.txt` |
| `--report` | Отчёт |
| `--mark-done` | Отметить все текущие файлы как обработанные |

`Урезать.bat` вызывает программу без дополнительных параметров, то есть по правилу размера и со сжатием 65.

## Ограничения

- Только Warcraft III 1.26: BLP1 и MDX версии 800. Модели Reforged не поддерживаются.
- Прогрессивные JPEG внутри BLP не пережимаются: такие текстуры пишутся в журнал как `JPG ошибка … — без пережатия` и остаются как были. Уменьшение размера для них работает.
- Архивы `.w3x` и `.mpq` не открываются, нужна распакованная папка.

## Сборка

Запустите `src\build.bat`. Нужен только компилятор C# из .NET Framework 4, он есть в любой Windows. Собранные `ChoiceOptimizer.exe` и `ChoiceOptimizerGui.exe` появятся рядом с папкой `src`.

`AssemblyInfo.cs` и `app.manifest` добавляют в exe сведения о файле. Без них антивирусы (например, Avast) по эвристике принимают программу за вирус.
